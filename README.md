# 🚦 Road Rakshak 2.0

AI Powered Road Safety Reporting System built using Streamlit and Google Gemini.

## Features
- Road hazard detection from images
- Live camera road analysis
- Accident data analytics
- Automatic civic complaint letter generation

## Tech Stack
- Python
- Streamlit
- Google Gemini AI
- Pandas
- Matplotlib

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
